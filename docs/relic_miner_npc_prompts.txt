OBSERVAÇÕES IMPORTANTES
============================================================

1. Evite pedir personagens segurando objetos nas mãos.
   Melhor gerar todos sem armas, ferramentas ou tochas nas mãos.

2. Tocha, espada, picareta, machado e outros itens devem ser objetos separados.
   No Godot, eles podem ser presos nas mãos usando BoneAttachment3D.

3. Para manter consistência visual, use sempre termos como:
   - semi-realistic medieval fantasy RPG
   - game-ready 3D model
   - PBR textures
   - riggable character
   - style similar to classic Oblivion/Gothic fantasy RPG

4. Para NPCs simples, eles não precisam de muitas animações.
   O básico seria:
   - idle
   - walk
   - talk / gesture

5. Para o personagem principal, o ideal seria ter:
   - idle
   - walk
   - run
   - jump
   - attack
   - mining / pickaxe action
   - interact / pick up
   - hold torch / carry pose
